# DSH 客户端 v1.3.0 升级说明

> 发布日期：2026-08-18
> 升级自：v1.2.1
> 安装包：`install-dsh-v1.3.0.exe`（约 150MB，含本地 OCR 引擎）

---

## 🆕 v1.3.0 更新内容

### ✨ 新功能：本地 OCR 图片识别

**让 DeepSeek 模型"读懂图片"**：DSH 选用模型无视觉模块、原生不支持图片，此前发图会直接失败（"当前模型不支持图片"）。本次新增 `dsh-plugin-ocr` 插件，把图片先经**本地 OCR 引擎**转成文字再喂给模型，模型虽看不见图，但能读到图里的字，直接基于文字作答。

- **技术链路**：GUI 拖图 → apiproxy 落盘 + 能力检查放行 → `agent/pre-step` hook 把 image block 替换为 OCR 文本 → DeepSeek 适配器（纯文本）→ 基于文字回复。
- **本地引擎**：PaddleOCR-json v1.4.1（离线、中文优先），不依赖外部 API、不上传图片。
- **效果**：正确识别图内文字（中文/英文/数字）；模型能直接回答图片内容问题，无"看不到图片/请给图片路径"诉苦。
- **使用**：会话里直接拖入图片 + 提问即可。

### 📦 引擎集成进安装包（安装即用）

OCR 引擎（约 250MB）此前需从外部源手动复制，现**已随安装包自动部署**：

- 客户端启动时自动检测并部署引擎到 `~/.dsh/ocr/`（幂等，缺失才复制）。
- **换机器 / 重装后，装上客户端即可直接用 OCR，无需任何手动复制**。

### 🔧 其他

- 更新自检逻辑沿用 v1.2.1 的 Node 直连下载 + 8 线程分段（绕过代理、带进度）。

---

## 🔒 重要说明

- 引擎仅本机运行，图片不出本机；如需彻底关闭 OCR，可在设置中手动移除 `~/.dsh/ocr/`（插件会降级为提示无法识别，不影响正常消息）。
- 受图片质量影响：英文空格可能粘连、手写/艺术字识别效果有限。

---

## ⬆️ 升级方式

1. 下载 `install-dsh-v1.3.0.exe` 并运行安装（安装目录可替换旧版）。
2. 或从客户端状态栏「更新」按钮静默更新。
3. 安装完成后重启客户端，首次发图即走本地 OCR。

> 旧版 `app.asar` 备份：`resources/app.asar.bak-v1.2.1`（如需回滚可覆盖恢复）。
