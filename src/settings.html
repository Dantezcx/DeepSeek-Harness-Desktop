备份管理（压缩包快照）

备份 = 把会话/API/设置 + 插件与插件设置（dsh-web-ui 全家桶等）打包成带日期的 tar.gz 直接上传到 WebDAV 根目录（保留最近 10 份）；恢复时按日期选择，会覆盖本地。

🤝 继承外部 AI 规则

从其他 AI 工具（Claude Code / Cursor / Gemini / Codex 等）继承行为规则：自动搜索其规则文件 → 精简改写为 dsh 可用规则（自动剔除该软件专属特性）→ 写入长期记忆。仅在你点击确认后才会读取文件。
